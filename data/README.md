Production requires data/pittsburgh.geojson, WGS84 longitude/latitude.
Download the Pittsburgh City Boundary GeoJSON from the City of Pittsburgh / WPRDC:
https://data.wprdc.org/dataset/pittsburgh-city-boundary
Verify the resource is the entire city boundary, not county, ZIP or neighborhood boundaries.
Record the source and date in this file. No boundary has been downloaded or verified yet.
The scanner refuses to start without a valid file. It excludes border points and missing coordinates.
Tests use a synthetic polygon, which must never be used in production.
