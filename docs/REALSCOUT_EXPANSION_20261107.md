# RealScout intake and inclusive tax ceiling

Effective November 7, 2026: verified annual property taxes plus the $100
buffer must be **at most $2,400**. Exactly $2,300 annual tax passes. A value
above $2,300 fails without rounding it down. Assessment calculations remain
estimates and cannot establish qualification. Asking price is at most $200,001.
Single-family, bedroom, bathroom, size and geographic restrictions still apply.

The exact, already consented RealScout sender has a separate, bounded historical
Gmail cursor. It never resets the normal intake cursor or first-discovery dates.
Parser v4 supports slash-separated area names and MJML Exclusive alerts. An
Exclusive badge alone does not establish Active status. Undisclosed addresses
are retained as unresolved evidence blocks, never invented property identities.

The existing Render source worker drains incomplete intake every five minutes.
After completion its six-hour interval is capped by the next 07:45 Israel check.
The existing daily-email job also performs a final bounded, authenticated
selected-sender intake before preparing its existing idempotent outbox record.
This endpoint does not fetch RentCast, send email, or fetch other source feeds.
Transient intake failures do not suppress legitimate daily mail.

Received-alert coverage is distinct from saved-search or complete-market
coverage. Editing upstream RealScout searches requires an authenticated
RealScout session. No direct MLS/API entitlement is inferred from listing mail.
