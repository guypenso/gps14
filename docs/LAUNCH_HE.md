# הפעלת RentalSourcing — מצב סופי להכנת ההשקה

הקוד נבדק מול 100 מודעות אמיתיות ושלוש היסטוריות מס. בדיקת ההפעלה המלאה של
Gunicorn/Flask ו־PostgreSQL הצליחה מקומית. אין כרגע פריסה בענן או שליחת מיילים.
בדיקת הנתונים והספירות מפורטות ב־LIVE_ACCEPTANCE_HE.md.

## פעולות משתמש מינימליות

1. לחבר את Render לצ׳אט ולחשבון GitHub עם גישה ל־guypenso/gps14.
2. לאשר בנפרד את יצירת Web Starter, PostgreSQL ו־Cron: בסיס של כ־$15.50 לחודש,
   לפני חריגות/מסים/דומיין. אין להחיל Blueprint בתשלום לפני אישור.
3. לאחר שהשירותים עלו בהצלחה, להגדיר בסודות שירות הסריקה RENTCAST_API_KEY, RESEND_API_KEY, EMAIL_FROM, EMAIL_TO.
   השולח חייב להיות מאומת ב־Resend. אין להדביק מפתחות בצ׳אט או לשמור אותם במאגר.
4. אחרי בדיקת בריאות ונתונים בענן, לאשר מייל בדיקה ומכסת סריקה מתמשכת.
   ארבע הקריאות הקודמות נוצלו במלואן; אין לחדש אותן באמצעות החלפת מזהה אישור או DB.

הוראות ניסיון הפריסה המעודכנות, כולל מסך התשלום והמשתנים, נמצאות ב־[RENDER_DEPLOYMENT.md](RENDER_DEPLOYMENT.md).

החיבור ובחירת מאגר ל־Blueprint נפרדים מאישור יצירת משאבים בתשלום. קישור הכנת ההתקנה:
https://render.com/deploy?repo=https://github.com/guypenso/gps14

## הגדרות המימוש המוכנות

- render.yaml מצביע במפורש ל־master, עם autoDeployTrigger=checksPass.
- שני השירותים חולקים DATABASE_URL פנימי; PostgreSQL חסום לגישה ציבורית.
- נכלל גבול רשמי מקומי: הבנייה מאמתת אותו ללא הורדת רשת או קריאת ספק.
- דף הייצור פרטי: DASHBOARD_USERNAME=owner וסיסמה שנוצרת ב־Render.
- RentCast ו־Resend כבויים, API_APPROVAL_ID ריק ו־APPROVED_API_REQUESTS=0.
- עמודים של עד 500 מודעות, עד 20 עמודים לריצה; מכסה מצומצמת עוצרת וממשיכה מה־cursor,
  מסמנת סריקה חלקית ומשאירה Pending Verification. אין טענה לכיסוי מלא בתקציב נמוך.
- Cron ב־12:00 ו־13:00 UTC; האפליקציה מאפשרת רק 08:00 America/New_York כולל DST.
- מחיר מופחת קודם בתור; מטמון מס מונע קריאות כפולות, ומידע מס חסר נבדק שוב בהדרגה.
- מייל כושל/חלקי אינו מוצג כ״אין עסקאות״. outbox ומפתח idempotency מונעים כפילות.

## העברת המדגם למסד הענן — לביצוע טכני לאחר החיבור

`python -m rentalsourcing.transfer` משתמש ב־SOURCE_DATABASE_URL וב־DATABASE_URL
המוגדרים באופן פרטי. הכלי דורש מסד יעד ריק, נועל סריקות, מעתיק במצטבר אטומי,
ושומר מכסות ו־outbox. אין בו קריאת RentCast או שליחת מייל. העברה ליעד לא ריק נדחית.
סודות חיבור ונתונים אמיתיים אינם נשמרים ב־Git. יש לתכנן ולבדוק גם שחזור גיבוי ב־Render.

## העלות והכיסוי

Web $7 + DB $6 + אחסון 5GB $1.50 + Cron לפחות $1 = כ־$15.50 לחודש.
Resend בהיקף מייל יומי יחיד צפוי להתאים למסלול חינמי. RentCast Developer כולל 50
בקשות בחודש; 30–31 קריאות מודעות משאירות כ־19–20 להשלמות מס, בהיעדר שימוש אחר.
זה אינו מספיק לאימות מיידי של כל 42 המועמדים שכבר נצפו, ובוודאי אינו מבטיח את כלל העיר.
מטמון חוסך קריאות חוזרות; היקף מועמדים חדשים/מידע חסר/עדכוני מחיר ייקבע רק לאחר הפעלה.

דוגמה חשבונית בלבד: 330 בקשות בחודש עולות $56 ב־Developer, כלומר כ־$71.50 עם האירוח.
ב־930 בקשות, Foundation $74 זול יותר: כ־$89.50 עם האירוח. לא הופעלו מסלולים או חריגות.
יעד $15–30 אפשרי לתצורה מוגבלת במכסה; לא ניתן להבטיח במסגרתו אימות מלא ועדכני לכל העיר.
יש לאשר במפורש כל מכסת API מתחדשת/חריגה; מחיר מסך ההזמנה הוא הקובע.

מקורות שנבדקו: https://render.com/pricing ; https://render.com/docs/cronjobs ;
https://www.rentcast.io/api ; https://resend.com/pricing .
