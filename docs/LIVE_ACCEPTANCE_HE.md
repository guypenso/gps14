המשתמש אישר עד ארבעה ניסיונות RentCast מתוך יתרת 50 קריאות כלולות שדיווח עליה.
בוצע ניסיון אחד בלבד ל־Sale Listings, עם limit=100 וכל המסננים המקוריים.

אין נתונים עסקיים שאפשר לסנן ואין להציג זאת כ״נבדקו 100 נכסים ולא נמצאו עסקאות״.
לא בוצעו שליפות מס או ניסיונות חוזרים; שלושת הניסיונות האחרים לא נוצלו.

תיעוד הניסיון המקורי שמר סוג שגיאה וסיבה אך לא שמר את קוד הסטטוס המספרי או את גוף
השגיאה. אין ראיה מספקת לייחס את הדחייה בוודאות ל־RentCast או ל־proxy.
הקוד הוקשח כך שכשל HTTP עתידי ישמור סטטוס מספרי וסיווג גוף בטוח, בלי להדפיס גוף
תגובה שעלול להכיל סודות. תוספת זו נבדקה מקומית ולא הצדיקה ניסיון API חוזר על אותה בקשה.

הניסיון, מונה המכסה ותוצאת הסריקה הכושלת נשמרו ב־PostgreSQL מקומי עם volume מתמשך.
אין במאגר GitHub גוף נתוני נכס, מפתח API, סיסמה או כתובת היעד האישית.
הדשבורד המקומי התחבר למסד הזה והציג 0 מודעות שהתקבלו וסריקה כושלת אחת, ללא Demo.

בנפרד, הורדת הגבול הרשמי מ־services1.arcgis.com נחסמה ב־Proxy CONNECT עם 403 Forbidden.
זו חסימת יעד רשת מוכחת ונפרדת מתוצאת RentCast. אין עקיפה או החלפה בגבול דמה.
אפשר לאפשר את היעד בסביבת Codex, או לבצע את ההורדה בשלב הבנייה ב־Render לאחר אישור פריסה.

## מה פעיל ומה אינו פעיל

- שרת Gunicorn/Flask + PostgreSQL נבדקו מקומית דרך HTTP: דף/API/health החזירו 200.
- readyz החזיר 503 כי הגבול הרשמי אינו זמין; אין הצגת readiness מלא שאינו אמיתי.
- UI מסונן, מסים, פסילות, מיקום, Cache וכפילויות נבדקו מול נתוני בדיקה שמסומנים כסביבת בדיקה.
- מסלול Resend נבדק בתשובות מדומות ובתצוגה ללא שליחה בלבד. לא התקבל מפתח Resend בסביבה.
- כתובת היעד התקבלה ונשמרה רק בהגדרות הפרטיות; יש להגדיר אותה גם ב־Render לפני הפעלה.
- לא נוצרו שירותי Render ולא התקבלה כתובת ציבורית. יצירת המשאבים דורשת חיבור לחשבון ואישור חיוב.
